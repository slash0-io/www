docusign/connect-webhooks

Direction: ingress. Ranges DocuSign connects from (webhook delivery); use them in security group ingress rules on your receiving endpoints.

loading ranges from the feed…

This purpose currently publishes more IPv4 ranges than the default rules-per-SG quota (60). Each CIDR consumes one rule; the hosted prefix list spends quota once per list instead. Details in the FAQ.

Terraform

data "egress_ranges" "docusign_connect_webhooks" {
  service = "docusign"
  purpose = "connect-webhooks"
}

resource "aws_security_group_rule" "docusign_connect_webhooks" {
  type              = "ingress"
  from_port         = 443
  to_port           = 443
  protocol          = "tcp"
  cidr_blocks       = data.egress_ranges.docusign_connect_webhooks.ipv4_cidrs
  security_group_id = aws_security_group.app.id
}
