Direction: both. PayPal publishes these ranges for traffic in either direction; use them in the rule direction your integration needs. The example below shows egress.

This purpose currently publishes more IPv4 ranges than the default rules-per-SG quota (60). Each CIDR consumes one rule; the hosted prefix list spends quota once per list instead. Details in the FAQ.

Terraform

data "ipranges_egress" "paypal_all" {
  service = "paypal"
  purpose = "all"
}

resource "aws_security_group_rule" "paypal_all" {
  type              = "egress"
  from_port         = 443
  to_port           = 443
  protocol          = "tcp"
  cidr_blocks       = data.ipranges_egress.paypal_all.ipv4_cidrs
  security_group_id = aws_security_group.app.id
}
